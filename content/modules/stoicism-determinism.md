quiz_excerpt: >-
  Chrysippus argued that a cylinder rolls because it is pushed, but rolls the
  way it does because of its own shape. The Stoics used this to keep
  responsibility inside a determined world. Whether a language model's outputs
  count as "its own shape" is exactly the question this module opens.
